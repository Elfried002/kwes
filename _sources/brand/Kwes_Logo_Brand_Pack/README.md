# Kwes — Logo & Brand Pack

Ce pack regroupe les premiers assets visuels de l'identité Kwes.

## Contenu

- `01-logos/` : logo statique extrait de l'animation, version 2x.
- `02-animation/` : GIF animé en boucle et six images individuelles de l'animation.
- `03-icons/` : icône vectorielle SVG de l'Hybrid Orb et exports PNG/favicons lorsqu'ils sont disponibles.
- `04-previews/` : planche de concept et aperçu des images de l'animation.
- `05-guidelines/` : recommandations d'utilisation.

## Direction visuelle

- Bleu électrique : `#267BFF`
- Cyan lumineux : `#5CE7FF`
- Violet : `#6B58FF`
- Violet profond : `#100B32`
- Blanc froid : `#F7FBFF`

## Règles d'utilisation

1. Utiliser le GIF pour les supports de présentation et les aperçus animés.
2. Utiliser le SVG pour les interfaces, logos adaptatifs et tailles variables.
3. Utiliser les PNG pour les contextes qui ne prennent pas en charge SVG.
4. Conserver un contraste suffisant sur les fonds.
5. Ne pas étirer, recolorer ou déformer le symbole sans décliner une variante officielle.
6. Le GIF est une animation de marque illustrative : il ne reflète pas à lui seul l'état réel de l'agent.
7. Dans l'application, l'Hybrid Orb doit être une animation interactive pilotée par les événements réels : écoute, réflexion, exécution, parole, succès, erreur et attente d'approbation.

## Important — statut des assets

Ce pack est une première base visuelle exploitable pour l'intégration et la discussion de marque. Le SVG est une interprétation vectorielle propre du symbole orb/waveform, et non une vectorisation pixel-perfect du GIF. L'animation interactive de production (Rive/Lottie ou SVG/CSS/Canvas) doit être développée séparément et reliée à la machine à états de Kwes.
