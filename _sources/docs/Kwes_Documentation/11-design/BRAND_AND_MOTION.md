# Identité de marque et animation — Kwes

## 1. Identité

Nom : Kwes  
Descripteur : Personal Autonomous AI Agent  
Signature : Your intelligence. Your actions. Your world.

L'identité doit être indépendante des marques dont elle s'inspire.

## 2. Symbole Hybrid Orb

Une sphère lumineuse composée de particules et de flux doux. Elle représente une intelligence en mouvement, capable d'écouter, réfléchir, agir et répondre.

## 3. Déclinaisons

- logo vectoriel statique ;
- icône d'application ;
- version claire et sombre ;
- GIF en boucle pour présentation ;
- animation Rive/Lottie pour le produit ;
- fallback statique pour faible puissance ou motion réduit.

## 4. Storyboard GIF

Boucle suggérée :
1. particules dispersées ;
2. particules convergeant vers un volume ;
3. sphère lumineuse stabilisée ;
4. légère pulsation ;
5. onde de lumière ;
6. retour fluide à l'état initial.

Le GIF est décoratif. L'état fonctionnel réel de Kwes doit aussi être indiqué par du texte accessible.

## 5. États produit

Les états Idle, Listening, Thinking, Executing, Speaking et Error doivent avoir une animation distincte, mais cohérente.

## 6. Performance

- animation limitée en taille ;
- réduire le nombre de particules sur mobile ;
- utiliser `prefers-reduced-motion` ;
- éviter une animation GPU permanente excessive ;
- charger l'animation après le contenu essentiel ;
- prévoir un poster statique.

## 7. Propriété intellectuelle

Ne pas reprendre le logo Dots, le logo OpenAI ou une animation propriétaire. Créer un langage visuel original à partir du brief Kwes.
