# Glossaire — Kwes

| Terme | Définition |
|---|---|
| Agent | Système qui poursuit un objectif à l'aide d'outils |
| Orchestrateur | Composant qui coordonne plan, outils et résultats |
| LLM | Modèle de langage |
| Tool calling | Mécanisme par lequel le modèle propose un appel d'outil |
| Skill | Capacité versionnée avec permissions et schémas |
| Worker | Processus serveur exécutant une tâche asynchrone |
| Queue | File de travaux à exécuter |
| PWA | Application web installable |
| ASR | Reconnaissance automatique de la parole |
| TTS | Synthèse vocale |
| Code-switching | Alternance de plusieurs langues dans un échange |
| RLS | Row Level Security, règles d'accès par ligne |
| pgvector | Extension PostgreSQL pour recherche vectorielle |
| Idempotence | Propriété qui évite qu'une répétition produise plusieurs effets |
| SSRF | Vulnérabilité permettant de faire requêter le serveur vers des ressources internes |
| Prompt injection | Tentative de faire détourner le comportement du modèle via des données non fiables |
| ADR | Architecture Decision Record |
| Hybrid Orb | Symbole animé Kwes combinant sphère et particules |
